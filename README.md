# Kirimase CLI

A Rails-like CLI for building full-stack Next.js apps faster.

## Installation

```bash
# Install dependencies
npm install

# Build the CLI
npm run build

# Link the CLI globally (optional)
npm link
```

## Development

```bash
# Watch mode for development
npm run dev

# Run the CLI
npm start
```

## Usage

Once installed, you can run the CLI using:

```bash
kirimase
```

The CLI will guide you through:
1. Creating a new project
2. Selecting a framework
3. Configuring TypeScript support

## Commands

Currently supports:
- Project initialization
- Framework selection (Next.js, Express, Fastify)
- TypeScript configuration
